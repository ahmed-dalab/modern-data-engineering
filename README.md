# Modern Data Engineering + AI Systems Journey

> A public learning journey documenting my transition from Software Development into Data Engineering, Data Analysis, and AI Systems.

## Overview

This repository serves as a structured learning journal, project portfolio, and knowledge base documenting my journey into **Modern Data Engineering and AI Systems**.

As a software developer, I want to develop a deep understanding of data before moving further into advanced analytics, machine learning, and AI engineering.

Rather than jumping directly into AI model development, I have chosen to build a strong foundation in:

* Data Engineering
* Data Analysis
* Database Design
* Data Architecture
* Analytics Systems
* Distributed Data Systems
* AI Integration

My long-term goal is to become capable of designing, building, and scaling data-driven applications while understanding the complete lifecycle of data from generation to consumption.

# Why This Repository Exists

I believe that understanding data is one of the most valuable skills for modern software engineers.

Many developers learn frameworks and tools but lack a deep understanding of:

* How data moves through systems
* How analytics platforms work
* How large-scale databases operate
* How AI systems consume and utilize data

This repository documents my effort to build that foundation through consistent learning, practical projects, and continuous reflection.

---

My goal is not simply to finish books or courses.
